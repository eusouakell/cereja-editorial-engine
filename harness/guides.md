# Guides

**Descriptive + feedforward**

Guides give each editorial role the minimum sufficient authoritative context needed for its job.

## Current Guide surfaces

| Guide | Status | Typical consumer |
|---|---|---|
| Editorial Packet | documented / actively used as contract | all composition roles |
| Núcleo canonical context | implemented as repository knowledge | researcher / curator / composer |
| voice guidance | provisional | composer / editor / voice reviewer |
| format contracts | documented | channel renderers |
| content-token schema/taxonomy | documented | tokenizer / curator |
| Flame | documented / under validation | visual renderers |
| examples / prior published issues | available as historical evidence | research / composition when routed |

## Context isolation

Renderers should not receive the entire research corpus by default.

Example:

```text
Instagram Renderer
← approved thesis
← selected tokens
← rights metadata
← Flame constraints
← Instagram format contract
```

If a renderer needs evidence outside that bundle, it escalates instead of guessing.

## Historical content rule

Past published content can guide style/history but does not automatically become current truth.
