# Guards

**Normative + feedforward**

Guards constrain editorial work before an invalid or consequential action proceeds.

## Editorial Guards

| Guard | Status | Consequence |
|---|---|---|
| approved thesis/open-question required for Thought Leadership composition | documented | stop / request decision |
| claim scope cannot be broadened by renderer | documented | return to evidence review |
| new claim requires evidence review | documented | stop / escalate |
| rights metadata required for third-party media | documented | block asset use |
| sensitive disclosure requires Kell approval | documented | pause |
| client/partner reference requires approval | documented | pause |
| science/health interpretation cannot bypass evidence review | documented | escalate |
| renderer receives minimum sufficient context | documented | restrict context surface |
| publication requires Kell approval | documented | block publication |

## Rights

A format renderer may shorten, reorder or recompose approved material.

It may not use the format transition as permission to:
- invent evidence;
- make an image legally reusable;
- imply endorsement;
- remove required attribution;
- convert a private research note into public content.

## Human Guards

Kell's approval acts as a Guard before:
- publication;
- a new thesis becoming public;
- sensitive personal disclosure;
- science/health interpretation;
- client/partner reference;
- consulting positioning.
