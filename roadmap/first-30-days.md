# First 30 days

## Week 1 — Inventory
Index all public Cereja issues, sections, brand/about/style sources, handoff decisions and benchmark records.

## Week 2 — Thesis + evidence
Select 10–20 recurring topics and classify each as question, prior statement, hypothesis or current thesis.

## Week 3 — Retrospective audit
Run gates on 3 previously published pieces to calibrate false positives.

## Week 4 — New experiment
Choose one new cross-domain topic.
Run A/B/C/D.
Measure revision distance and time.
Decide how to restart publication.
