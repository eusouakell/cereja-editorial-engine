# Instagram template — revista visual

Purpose: make Cereja feel like an editorial object, not a corporate educational carousel.

## Default grammar

```text
COVER
question / phrase / image

SIGNAL
what happened or what caught attention

CONTEXT
what we are looking at

CONNECTION
the unexpected bridge

REFERENCE
culture / science / design / object / person

INTERPRETATION
what Cereja sees in it

EXIT
question / provocation / invitation
```

## Constraints

- Avoid "5 insights you need to know" unless the subject genuinely calls for a list.
- Visual pacing matters; text density should vary across cards.
- The carousel must stand on its own without reproducing the full newsletter.
- Images, screenshots, charts and cultural references require rights review.
- A visual renderer may shorten wording but cannot broaden a claim.
