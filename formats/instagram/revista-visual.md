# Instagram format contract — revista visual

Purpose: make Cereja Flamejante feel like an editorial object, not a corporate educational carousel.

## First decision: format

This file is **not a command to make a carousel**.

Use [Instagram Specialist Pipeline V0](../../guides/instagram-specialist-pipeline-v0.md):

```text
APPROVED STORY
→ INSTAGRAM STRATEGIST
→ choose: single image | carousel | Reel/video | Stories
```

Only use the carousel rules below when the approved format is carousel.

## Carousel house grammar

For Cereja Flamejante, a carousel always has three structural anchors:

1. **COVER 1** — first entry point;
2. **COVER 2** — second entry point that can stand alone and still advance the story;
3. **ENDING** — narrative closure + CTA appropriate to the primary goal.

Between them, add only the beats the story actually needs.

There is no mandatory number of slides.

## Possible semantic jobs

Middle frames may use jobs such as:

```text
SIGNAL
CORRECTION
CONTEXT
EVIDENCE
CONNECTION
CULTURAL CUT
REFERENCE
TURN
PAYOFF
INTERPRETATION
```

These are not a checklist and not a fixed order.

A frame exists only if it adds something the previous frame did not.

## Cover 1

The first frame should stop the scroll through the **object/story itself**, not marketing about the post.

It may use:

- a question;
- a surprising fact;
- a strong image/object;
- a tension;
- an incomplete but honest statement.

It cannot be deceptive.

## Cover 2

The second frame is a **second cover**, not a repeated title.

It should:

- make sense if shown first;
- add a new angle, correction, consequence or more concrete promise;
- create another reason to continue;
- avoid repeating the same sentence with different words.

## Ending + CTA

The story must feel complete before the CTA is perceived.

The CTA depends on the primary job:

- send/share: often no explicit “share this” is needed;
- save: only reinforce future utility when real;
- comment: open a genuine question;
- subscribe/traffic: contextual, secondary invitation;
- relationship: continuation or recurring ritual.

## Text economy

Image carries the story whenever possible. Text anchors meaning.

Avoid:

- mini-essays on every card;
- title + paragraph + footer repeated mechanically;
- explanatory labels for what the visual already communicates;
- disclaimers in the artwork when provenance/alt text can carry them without misleading.

Text density may vary deliberately between frames.

## Visual rhythm

Use Flame.

Prefer variation in:

- scale;
- whitespace;
- photography vs illustration vs typography vs evidence;
- crop;
- density;
- quiet vs statement frames.

Avoid generic “AI carousel” defaults and one template stretched across every beat.

## Constraints

- The carousel must stand on its own without reproducing the full newsletter.
- Images, screenshots, charts and cultural references require rights/provenance review.
- A planner or renderer may shorten approved wording but cannot broaden claim scope.
- New factual claims or a new thesis return to evidence/thesis review.
- A visual renderer/executor must not reopen story or channel strategy.

## Distribution context

Use this contract with [Instagram strategy V1](../../growth/instagram-strategy-v1.md).

Objective and success metrics must be declared **before** publication so learn-back evaluates the post against its intended behavior.
