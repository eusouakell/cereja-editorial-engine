# YouTube — spoken explainer / demonstration

**Status:** pilot format contract

## Job

Use speech, presence, screen/demo, motion or audiovisual evidence when seeing/hearing materially improves understanding.

Secondary strategic value:
- speaking/teaching proof;
- evergreen discoverability;
- reusable media.

YouTube is not a requirement for every cycle.

## Use when

At least one is true:
- screen/demo matters;
- spoken reasoning is stronger than prose;
- performance/pacing is part of the value;
- visual sequence clarifies a system;
- the result can serve as credible speaking/teaching evidence.

## Minimum inputs

- approved packet/thesis;
- Narrative Craft route;
- visual/demo assets with rights;
- discoverability notes;
- accessibility plan;
- production effort estimate;
- CTA.

## Spoken-first design

Do not write an essay and read it to camera.

Prefer:

```text
COLD OPEN / OBJECT / QUESTION
→ ORIENT THE VIEWER
→ FIRST BEAT / ACTION
→ REFLECTION
→ TURN / DEMO / CONTRAST
→ IMPLICATION
→ CLEAN PAYOFF / NEXT STEP
```

Use Brazilian oral-storytelling craft where useful: rhythm, pause, presence, observation, causos/concrete detail and cultural connection. Do not imitate another person's accent/persona.

## Pilot duration

No mandatory duration. As a starting hypothesis, prefer the shortest duration that earns the explanation. Do not pad to platform conventions.

## Accessibility

Plan:
- accurate captions;
- transcript or equivalent text access when feasible;
- spoken description of essential visual information;
- sufficient visual contrast/readability;
- no meaning dependent only on rapid motion;
- reduced-motion alternatives where an embedded/web experience requires them.

## Discoverability

Record:
- one clear viewer question;
- title/description language grounded in the real subject;
- chapter markers when they improve navigation;
- links to canonical evidence/repos;
- relationship to other Cereja artifacts.

## Gate

- audiovisual medium adds value;
- hook is honest;
- story route is coherent;
- no unsupported claim hidden behind editing;
- rights cleared for music/image/video;
- accessibility plan complete;
- effort still within pilot capacity;
- Kell approves publication.

After the first video, compare outcome value with human production/review cost before scheduling the next one.
