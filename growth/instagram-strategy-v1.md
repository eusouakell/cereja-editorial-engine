# Instagram strategy V1 — Cereja Flamejante

Status: **operating strategy for validation with real posts**.  
Date: 2026-10-05.

## Objective

Use Instagram as **visual editorial discovery** for Cereja Flamejante.

The job is not to summarize every newsletter or manufacture daily volume.

A successful post should make someone:

- stay because the object/story is interesting;
- send it because another person comes to mind;
- follow because the account has a recognizable editorial point of view;
- occasionally move to the newsletter when the longer reading is worth it.

## What is verified about ranking

Adam Mosseri publicly named three top ranking signals in January 2025:

1. **watch time**;
2. **likes per reach**;
3. **sends per reach**.

He also distinguished the surfaces: likes matter somewhat more for connected reach; sends matter somewhat more for reaching people who do not already follow the account.

Reference:
- Social Media Today summary quoting Mosseri: https://www.socialmediatoday.com/news/instagram-shares-algorithm-insights-2025/738034/

Instagram also described recommendation changes intended to give original creators more initial distribution to a small relevant non-follower audience and expand reach when response is positive.

Reference:
- Social Media Today summary of Instagram recommendation guidance: https://www.socialmediatoday.com/news/instagram-reels-recommendations-tips/741030/

### What we will NOT canonize as fact

Do not build the strategy around unsupported formulas such as:

- “a send is worth X likes”;
- a mandatory number of slides;
- one universal hook length;
- one perfect posting hour;
- “saves are the #1 ranking signal”;
- a fixed hashtag count.

Those can be hypotheses or benchmarks, never platform truth without current evidence.

## Cereja's advantage

Cereja should not compete as a generic “content tips” account.

Its distinctive material is:

- unexpected connections;
- cultural/technical/scientific objects;
- Kell's actual curiosity and curation;
- strong visual art direction;
- references worth opening;
- evidence/provenance when a claim matters;
- a rhythm that can jump from one object to another without forcing one thesis.

The feed should feel closer to an **independent visual magazine** than to a marketing carousel factory.

## Four content jobs

### 1. Sendable discovery

Goal: unconnected reach / sends.

Question:

> What in this post makes a reader think of one specific person?

Good material:
- an unexpected adaptation;
- a bizarre historical/scientific detail;
- a cultural connection;
- an object with a strong “você sabia?” quality, without clickbait wording.

The send impulse should come from recognition or curiosity, not “marque 3 amigos”.

### 2. Visual rabbit hole

Goal: dwell/swipe time.

Start with one concrete object and reveal the research path.

Possible flow:

```text
OBJECT
→ DETAIL
→ CONTEXT
→ UNEXPECTED CONNECTION
→ REFERENCE
→ OPEN EXIT
```

Do not turn every slide into a mini-essay.

### 3. Useful reference

Goal: save/return value, while remembering that saves are not a confirmed top-three ranking signal.

Examples:
- a book/film/tool with a specific reason to open it;
- a compact source desk;
- a visual comparison;
- a mini glossary only when the topic genuinely needs one.

Utility is editorial value, not “7 hacks”.

### 4. Reel / moving explanation

Goal: watch time + sends.

Use only when motion or spoken pacing adds something.

Default structure:

```text
0–2s   object / scene / claim visible immediately
2–6s   what are we looking at?
6–15s  detail that changes the reading
15–30s connection / second object
end    clean landing, reference or invitation
```

This is a starting grammar, not a compulsory duration.

No slow logo intro.

## Carousel anatomy

Cereja already has a useful visual-magazine grammar:

```text
COVER
SIGNAL
CONTEXT
CONNECTION
REFERENCE
INTERPRETATION
EXIT
```

Treat those as **semantic jobs**, not seven mandatory cards.

### Variants

#### A. Curiosity route

```text
strange object
→ what happened
→ one detail
→ unexpected bridge
→ reference
→ lingering question
```

#### B. Culture route

```text
work/person/object
→ detail
→ another work/person
→ what connects them
→ where to continue
```

#### C. Science/technology route

```text
specific finding
→ what was actually measured
→ what it does NOT prove
→ cultural/practical connection
→ source / next question
```

#### D. Build-in-public route

```text
artifact
→ problem
→ decision
→ failure/change
→ current result
→ what remains unresolved
```

The last variant is especially useful for Cereja Lab / Kell authority, but should not take over the editorial feed.

## First-frame rule

Frame 1 should contain the **object of curiosity**, not marketing about the post.

Prefer:

> Carrie também virou musical.

over:

> 5 curiosidades sobre adaptações que você precisa conhecer.

Prefer:

> A água de Marte pode ser mais velha que…

over:

> Essa descoberta vai mudar tudo o que sabemos sobre Marte.

The first frame can be incomplete. It cannot be deceptive.

## Text density

Vary density deliberately.

A sequence may contain:

- one nearly image-only frame;
- one short factual frame;
- one denser reference frame;
- one closing frame with almost no explanation.

Uniform text boxes make the work look templated even when the copy is good.

## Visual identity

Use Flame.

Avoid recognizable “AI carousel” defaults:

- identical rounded cards;
- decorative gradients;
- centered headline on every frame;
- pills/tags as decoration;
- generic 3D icons;
- stock AI imagery with no provenance;
- bento layouts without information logic;
- one template stretched over unrelated subjects.

Recurring identity should come from:

- type hierarchy;
- cherry/lime/ink palette;
- original flame/signature rules;
- cropping/art direction;
- editorial whitespace;
- source/provenance treatment;
- motion language when used.

## Originality and AI imagery

Instagram's recommendation direction favors original creators, which aligns with Cereja's approach.

Use generative imagery only as explicitly conceptual art.

Never:
- reconstruct the brand mark generatively;
- present conceptual AI imagery as factual evidence;
- use “AI look” as the visual identity of the account.

The rejected generated-flame experiment is the correct precedent: generation may propose; canonical brand authority can reject.

## Caption role

The caption should add a layer rather than narrate every frame again.

Possible jobs:

- one extra detail;
- source context;
- Kell's real reaction;
- a link between the post and the newsletter;
- credits/rights;
- invitation to continue.

Avoid a second full carousel written as caption.

## Stories

Stories are primarily relationship/continuation, not the main discovery engine.

Use for:

- link to the edition;
- one-question polls tied to a real editorial choice;
- behind-the-scenes research;
- “which rabbit hole should I open next?”;
- corrections/addenda;
- replies with consent.

Avoid empty highlight covers or engagement stickers without editorial purpose.

## Measurement

For each feed post record:

- format;
- topic/content job;
- reach;
- follower vs non-follower reach when available;
- watch time / average watch time for video;
- likes per reach;
- sends per reach;
- saves per reach as secondary diagnostic;
- profile visits;
- follows attributable in-platform when available;
- link clicks where available;
- publication date/time.

Use **rates**, not only raw counts.

Do not compare carousel raw likes directly with Reel views and call one “better”.

## Learning questions

After at least 6–10 real posts, ask:

1. Which objects generate sends?
2. Which openings retain attention?
3. Which visual structures are recognizable as Cereja without the logo?
4. Do cultural, scientific or build-in-public posts attract different followers?
5. Which posts create profile visits and newsletter movement?
6. Which formats cost too much effort for the return?
7. What did Kell enjoy making enough to sustain?
