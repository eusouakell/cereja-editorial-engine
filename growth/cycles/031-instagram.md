## Selection rule

Choose the flagship object by:
1. strongest standalone discovery;
2. clear send-to-someone reason;
3. rights feasibility;
4. visual potential;
5. enough evidence to deliver value inside Instagram;
6. no need to summarize the entire newsletter.

## First experiment recommendation

If newsletter approval does not materially change the candidates:

**Prefer Candidate D for the first controlled Instagram experiment** if evidence and source media can be verified.

Why:
- it can be explained with original diagrams/type rather than copyrighted entertainment stills;
- it crosses science + pop curiosity naturally;
- the post can be complete without forcing a newsletter summary;
