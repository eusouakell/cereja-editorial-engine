# Metrics

## Primary: Human Revision Distance
Measure how far the agent-assisted draft is from the final approved piece.

Track:
- substantially changed sentences;
- structural rewrites;
- unsupported claims removed;
- paragraphs newly written by Kell;
- approval without major rewrite.

## Context
- selected/excluded items;
- estimated tokens;
- stale-source warnings;
- authority conflicts.

## Editorial
- evidence coverage;
- thesis clarity;
- generic-language flags;
- gate findings;
- publish/no-publish.

## Operating
- research time;
- draft time;
- review time;
- total time;
- review loops.

## Measurement protocol to finalize

Define the revision-distance denominator and annotation rules before scoring. Blank scorecard cells mean not measured, not zero. Record model/version, settings, run date, context manifest and human reviewer for each A/B/C/D trial. No results are available in v0.1.
